# Divider

Source: `src/ui/divider/divider.tsx`

## Use For

- Horizontal separation between panel/dialog sections.

## API

- `thickness?: 'thin' | 'regular' | 'thick'` (default `regular`)

## Behavior

- Sets `--thickness` CSS var and renders full-width line.

## Guidance

- Use `thick` for strong section boundaries.
- Use `thin` inside dense control groups.
