# Link

Source: `src/ui/link/link.tsx`

## Use For

- Navigation links with MoMo text-link styling.

## API

- Wraps Next.js `LinkProps`
- `className?: string`
- `children`

## Behavior

- Forwards all `next/link` props.
- Adds underline + size styling from CSS module.

## Guidance

- Use for inline/nav links.
- Use `Button asLink` when action should look like a button.
